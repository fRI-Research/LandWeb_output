> **[NRV_summary](https://github.com/FOR-CAST/NRV_summary)**. LandWeb was not the only user of this
> module; other projects are unaffected and may continue to use it at their pinned commit.
>

> **`LandWeb-v2`** (`58f67cbe`) — the commit pinned by the
> [LandWeb `v2` branch](https://github.com/PredictiveEcology/LandWeb/tree/v2), which is also the
> tip of the `LandWeb` branch and the commit pinned by the **AB_NRV** project.

# LandWebOutput

Summarize the output for the LandWeb natural range of variation simulations.
Creates and saves seral stage maps, vegetation type maps, and patch maps during LandWeb simulations.

Please refer to `LandWeb_output.Rmd` for usage and other information.
